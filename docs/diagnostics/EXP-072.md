## Root Cause (Final, Confirmed)

The gate at `0x800AA0207` (`cmp byte [rbx+0x108], 0` + `jne`) blocks SignalSema because `[rbx+0x108]` contains a tagged pointer to an unresolved dependency. The dependency is never resolved because the CLEAR function (`0x800A9F750`) is never called (it's an async callback that should fire when a dependency completes, but no dependencies complete on SharpEmu).

**The NOP patch is a diagnostic, not a permanent fix.** The permanent fix would be:
1. Identify what dependency the tagged pointer at `[rbx+0x108]` represents
2. Implement the completion event that triggers the CLEAR function
3. Or implement the CLEAR function to fire at the right time
