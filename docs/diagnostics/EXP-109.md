### Remaining unknown:
The fundamental issue: a large class of IL2CPP-generated functions in this PRX are only reachable via indirect dispatch mechanisms (vtables, delegates, function pointer tables) that SharpEmu never triggers. The callback registration stores function pointers, but nothing ever reads them back and invokes them.

This is NOT a missing dispatcher — it's a **missing indirect call mechanism**. The IL2CPP runtime expects certain function pointers to be called via vtable/delegate dispatch, but SharpEmu's HLE doesn't implement the dispatch layer that would read these stored pointers and call them.

### Next EXP:
