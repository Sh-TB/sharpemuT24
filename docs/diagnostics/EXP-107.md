**Question:** Is PLT 218 (`0x804FC3720`) reached at runtime? Does it invoke the callback?

**Answer:** **Hypothesis B confirmed.** All 3 addresses in the callback invocation chain (`0x804F88AD0`, `0x804FA84E0`, `0x804FC3720`) had **ZERO INT3 hits**. The callback invocation path is **never reached** at runtime. The gap is NOT "PLT 218 runs but does the wrong thing" — it's that **nothing calls `0x804F88AD0` in the first place**. EXP-106's "PLT 218 is the missing link" claim was based on static analysis only; runtime evidence shows the entire invocation chain is unreachable.

**Confidence:** PROVEN by runtime tracing (INT3 at all 3 addresses, zero hits, clean run exit code 4).
