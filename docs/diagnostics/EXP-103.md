## EXP-102 Correction

### The Bug

The EXP-102 tracer (`_Exp102CallbackStorageTracer.cs`) used incorrect context record offsets:

| Register | Correct Offset (CTX_R14 from DirectExecutionBackend.cs:800) | EXP-102 Used | Result |
|----------|-----------------------------------------------------------|-------------|--------|
| R14 | 232 | 284 | Read wrong memory → got 0 |
| R12 | 216 | 276 | Read wrong memory → got 0 |

Both wrong offsets returned 0 (uninitialized memory in the context record), which was misinterpreted as "r14 = NULL" and "r12 = NULL."

### The Crash

The tracer then tried to dereference `[r14]` (address 0), causing a .NET JIT "Invalid Program" crash (exit code 134). This contaminated the run — the emulator aborted instead of reaching the normal stall. The reviewer correctly flagged this as a contamination risk.

### The Fix

1. Corrected R14 offset: 284 → 232
2. Corrected R12 offset: 276 → 216
3. Added NULL guard: skip memory dump if `r14 == 0` (prevents JIT crash)

### Corrected Runtime Evidence

```
[EXP102-XCHG] *** CALLBACK STORAGE ***
  r14=0x0000000020336760  ← VALID guest heap address (NOT NULL!)
  rax=0x00007FCEC8B6F320  ← callback pointer (host address)
  r12(IL2CPP context)=0x00007FCEC8EE0710  ← POPULATED (matches [0x808923D88])

  [r14] BEFORE xchg = 0x0000000000000000  ← slot was empty before
  [r14+0x10] = 0x0000000804FA1FE0  ← the callback function address!
```

### What Actually Happens

1. `r14 = 0x20337660` — a valid guest heap structure
2. `[r14]` before xchg = 0 (empty slot, waiting for callback)
3. `[r14+0x10] = 0x804FA1FE0` — the callback function is already referenced at offset +0x10
4. `xchg [r14], rax` stores the callback pointer at `[0x20337660]`
5. The run completes normally (exit code 4 = stall, no crash)

### Reconciliation with EXP-097

EXP-097 found `[0x808923D88]` (IL2CPP context) populated. EXP-102 (buggy) found `r12=0`. With the fix, `r12 = 0x7FCEC8EE0710` — which matches `[0x808923D88]`. **No contradiction.** The IL2CPP context is consistently populated throughout.
