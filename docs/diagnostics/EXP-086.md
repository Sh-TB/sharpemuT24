## Root Cause (preliminary)

The main thread is NOT deadlocked — it's running but not making progress. The most likely causes:

1. **Long computation in PRX code** — The main thread may be processing metadata in a tight loop inside the PRX without making HLE calls. The array_proc was entered, and the PRX may be iterating over a large metadata table.

2. **Error path from failed imports** — The `NOT_FOUND` errors for `sceKernelVirtualQuery` and `sceKernelDirectMemoryQuery` may cause the init to take a fallback path that doesn't properly set up GPU resources, leading to a spin or infinite retry.

3. **Missing HLE function** — The main thread may be calling an HLE function that returns immediately (FAST_PATH-style) without actually doing the work, causing the PRX to spin in a retry loop.
