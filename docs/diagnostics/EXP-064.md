## Root Cause

IL2CPP API stubs return NULL (0). Game stores NULL as function pointer. Game calls NULL. SharpEmu recovers 1,004 times. Host stack corrupted. `*** stack smashing detected ***: terminated`.

Same root cause as Harvest Days and Seeker My Shadow.
