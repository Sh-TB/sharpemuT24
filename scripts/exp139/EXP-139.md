## My Additional Considerations

### 139.5 Audit what `arch_init_gc` actually does on real PS5
Per Unity IL2CPP source patterns (Unity 2022.3.x), `arch_init_gc` is a Mono-derived runtime internal that:
1. Initializes the Boehm GC architecture (or Unity's modified variant)
2. Sets up the GC heap
3. Registers GC roots
4. Returns OK on success

For SharpEmu, we don't need a real GC — the managed heap is allocated by SharpEmu's memory subsystem. A stub returning OK should be sufficient to bypass the abort cascade.
