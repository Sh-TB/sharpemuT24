## Root Cause Status

### Hypothesis

**Function 0x8013FCE40 (the caller) has an early exit before offset +0x24E, preventing the init write to 0x801E518C8.**

### Evidence

- Function 0x8013FCE40 calls 0x8013EB6B0 at offset +0xDF9 (confirmed runtime)
- Init write at offset +0x24E is NEVER executed (INT3 not hit)
- The init write is BEFORE the call (+0x24E < +0xDF9)
- Therefore, 0x8013FCE40 must exit or branch before +0x24E

### Runtime Proof

- INT3 at 0x8013FD08E: **0 hits** (init write NEVER reached)
- INT3 at 0x8013EB6B0: **1 hit** (function called with [0x801E518C8]=0)

### Status: CONFIRMED

The init write at 0x8013FD08E never executes because function 0x8013FCE40 exits early before reaching offset +0x24E.
