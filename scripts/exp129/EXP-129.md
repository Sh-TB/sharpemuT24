# EXP-129 — Multi-Hypothesis Bootstrap Investigation

**Date:** 2026-08-04
**Status:** COMPLETE

## Finding

**Producer function IDENTIFIED at `0x801028d80` in eboot.bin** — the ONLY code in any binary that writes to `[rbx+0x90]` (counter) AND `[rbx+0x88]` (semaphore handle) AND calls SignalSema. However, this function has **0 direct callers** and is only referenced as a stored pointer in a read-only data segment. It is **NEVER called at runtime**.

## TEST A — 0x804FA1F90 Analysis
- **NOT the bootstrap submitter.** It's a once-init thunk: `mov rax, [rip+disp]; mov edi, [rax]; jmp once_init_PLT`
- Does NOT write to [reg+0x90], does NOT call SignalSema

## TEST B — VideoOut Bootstrap
- **sceVideoOutOpen: 0 occurrences in BOTH binaries**
- sceVideoOutAddFlipEvent: 4 string refs in eboot, 0 runtime calls
- **VideoOut is NOT required before WaitSema(0x81)**

## TEST C — XAKDgxcra6k
- NID string NOT found in eboot.bin
- Returns 0x80020002 (NOT_FOUND), game continues
- **NOT the blocker**

## TEST D — Semaphore 0x81 Signal Source
- 459 SignalSema callers in eboot.bin
- 14 have [reg+0x88] access within 0x40 bytes before
- **Only `0x801028d80` writes to BOTH [rbx+0x90] AND [rbx+0x88] AND calls SignalSema**
- This function has 0 direct callers, 0 LEA refs, 0 8-byte pointer refs
- Referenced only as 4-byte value at runtime ~0x80200f3f0 (read-only data segment)
- Called via function pointer table (vtable) — but the invoking code is never reached

## TEST E — Main Thread Execution Window
- real_init → once-init (0x804FA1F90) → dispatch loop (0x804F6E510) → WaitSema(0x81)
- Producer at 0x801028d80 is NEVER called in this path
- The dispatch loop blocks immediately because counter=0 and nobody signaled

## Confirmed
1. Producer function at 0x801028d80 — writes [rbx+0x90] and [rbx+0x88], calls SignalSema
2. Producer has 0 direct callers — called only via function pointer table
3. Producer NEVER called at runtime
4. 0x804FA1F90 is NOT the producer (it's once-init)
5. sceVideoOutOpen NOT imported — VideoOut not required
6. XAKDgxcra6k NOT the blocker
7. Dispatch loop called from within real_init
8. Only 0x801028d80 writes to BOTH [reg+0x90] and [reg+0x88]

## Rejected
1. "0x804FA1F90 is bootstrap submitter" — REJECTED (once-init thunk)
2. "VideoOut required before WaitSema(0x81)" — REJECTED (not imported)
3. "XAKDgxcra6k blocks init" — REJECTED (game continues)
4. "Vblank is missing trigger" — REJECTED (no vblank imports)
