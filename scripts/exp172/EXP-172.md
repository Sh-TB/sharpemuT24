## TEST 2: TLS Owner Identification

### TLS Segments (PT_TLS = 7)

| Module | Runtime Address | FileSize | MemSize | Align | Static Offset |
|--------|----------------|----------|---------|-------|---------------|
| EBOOT (module 1) | 0x801C80000 | 0x0 | 0xC0 | 0x8 | 0xC0 |
| libc.prx (module 2) | (in libc) | 0x180 | 0x468 | 0x10 | 0x530 |
| Il2cppUserAssemblies.prx (module 3) | 0x8086E9000 | 0x0 | 0x150 | 0x10 | 0x680 |

- **EBOOT** owns TLS block at static offset 0xC0 (memsz=0xC0, filesz=0 — all BSS/zero-initialized)
- **PRX (Il2cppUserAssemblies)** owns TLS block at static offset 0x680 (memsz=0x150, filesz=0 — all BSS/zero-initialized)
- Total static TLS: 0x680 + 0x150 = 0x7D0 bytes

### TLS Layout

SharpEmu uses AMD64 TLS Variant II:
- Static TLS blocks are placed BELOW the TCB (Thread Control Block)
- FS register points to the TCB
- Module 1 (eboot): offset 0xC0 from TCB
- Module 2 (libc): offset 0x530 from TCB
- Module 3 (PRX): offset 0x680 from TCB

## TEST 6: Decision Rule

### TLS Hypothesis: REJECTED

**Evidence:**

1. `__tls_get_addr` is **NEVER CALLED** at runtime — the game does not use dynamic TLS
2. TLS templates are **properly loaded and registered** for all 3 modules
3. `SeedTlsLayout` is called during thread setup — TLS blocks are initialized
4. **No TLS errors or warnings** in any runtime log
5. TLS setup is **identical** between argc=1 and argc=2
6. The crash is at WaitSema(0x81) — a **semaphore deadlock**, NOT a TLS access violation
7. The consumer function's failure is caused by `[0x801E51240] = NULL` (a BSS global, not TLS)

### Reason

The TLS hypothesis is rejected because:
- The caller RIP does NOT prove missing TLS initialization
- TLS values are correctly initialized (templates loaded, SeedTlsLayout called)
- The initialization writer is NOT skipped or missing
- The crash does NOT depend on TLS state — it depends on the BSS global 0x801E51240 being NULL

The TLS infrastructure is working correctly. The deadlock is caused by the initialization chain issue (argc=1 → r13d < 2 → skipped init → NULL global → consumer early exit → dispatch loop → WaitSema deadlock), NOT by TLS.
