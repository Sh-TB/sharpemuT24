## Global Lifecycle

### Is the global initialized?

**NO.** The global 0x801E51240 is never initialized.

### What value?

**0x0000000000000000 (NULL)** — BSS zero-initialized, never changed.

### Is it later cleared?

**NO.** Neither the initialization store (0x8013EF019) nor the clear store (0x8007FD8F9) was ever executed.

---

## Classification

### A. Store never executed

**CONFIRMED — 100% confidence**

Runtime evidence:
- INT3 at 0x8013EF019 (store RAX): **0 hits** — never executed
- INT3 at 0x8007FD8F9 (store 0): **0 hits** — never executed
- Global value at dispatch loop entry: **0x0000000000000000** (NULL — BSS initial value)

The store instructions exist in the binary (confirmed by static analysis in EXP-159) but are **never reached during Yatzi execution**.

### B. Store executed with NULL

**REJECTED — 0% confidence**

The store was never executed, so RAX value is irrelevant.

### C. Store executed correctly but later lost

**REJECTED — 0% confidence**

The store was never executed, so there was nothing to lose.

### D. Store unrelated to WaitSema

**UNKNOWN — 50% confidence**

The global is NULL, and 84 functions read from it. If any of these functions are on the path to PlayerLoop registration, the NULL global could cause them to skip initialization. However, we cannot prove a direct causal link to the WaitSema(0x81) deadlock without further instrumentation.

---

## Conclusion

**A. Store never executed.**

The global 0x801E51240 is **never initialized** — it stays at NULL (BSS zero) throughout execution. Both store instructions (at 0x8013EF019 and 0x8007FD8F9) are **never reached** during Yatzi startup.

This means the function containing the store (0x8013EB6B0) is **either never called** or **returns before reaching the store instruction** (e.g., due to an early return or conditional branch).

The NULL global may cause functions that read from it to skip critical initialization, potentially including PlayerLoop registration. However, proving this requires further investigation into which of the 84 read sites are on the PlayerLoop path.
