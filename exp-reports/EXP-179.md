### Task 2: Implementation

**File:** `src/SharpEmu.Libs/Kernel/KernelMemoryCompatExports.cs`
**Location:** After the existing `Free()` function (line ~1178)

**Approach:** All C++ operator new/delete variants delegate to existing `malloc`/`free` heap:
- `operator delete(ptr)` → calls `FreeLibcHeap(ptr)` if ptr != 0
- `operator new(size)` → calls `TryAllocateLibcHeap(size, ...)`
- Sized/aligned/nothrow variants ignore extra parameters
- operator delete[] is identical to operator delete (same heap)

**Build result:** 0 errors, 14 warnings (pre-existing)

## Root Cause (Original — Now Fixed)

```
SharpEmu did not implement _ZdlPv (operator delete, NID z+P+xCnWLBk)
  ↓
il2cpp_init's callee called operator delete via PLT 0x804FC2C80
  ↓
DispatchImport returned ORBIS_GEN2_ERROR_NOT_FOUND
  ↓
Caller entered error path → dispatch loop → WaitSema(0x81) DEADLOCK
```

**Fix:** Added 24 C++ operator new/delete HLE handlers in KernelMemoryCompatExports.cs, delegating to existing malloc/free heap.
