## Root Cause

**The crash function 0x80135DDD0 is called BEFORE the IL2CPP API chain (il2cpp_domain_get, il2cpp_class_from_name) is executed.** [0x801E51240] is NULL because no code sets it before the crash.

On a real PS5, the IL2CPP runtime initialization (inside il2cpp_init) would fully set up the runtime, including loading metadata, creating the domain, and making class pointers available. SharpEmu's native il2cpp_init returns 0 but doesn't complete this initialization.

### Broken layer: A) Metadata loading / Runtime initialization
