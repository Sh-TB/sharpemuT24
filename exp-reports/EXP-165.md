## EXP-165 Summary

### 1. First Missing Initialization

**Address:** 0x801E518C8

The global at 0x801E518C8 should receive an object pointer via `mov [0x801E518C8], rbx` at 0x8013FD08E, but this instruction NEVER executes.

### 2. Producer Function

**Address:** 0x8013FCE40 (parent function)

The init write at 0x8013FD08E (offset +0x24E) is inside function 0x8013FCE40. This function IS entered (it calls 0x8013EB6B0 at offset +0xDF9), but it exits early before reaching offset +0x24E.

### 3. Why Producer Does Not Execute

**Branch/Dependency:** Function 0x8013FCE40 has an early exit before offset +0x24E.

The init write at +0x24E is BEFORE the call to 0x8013EB6B0 at +0xDF9. Since the call IS reached but the init write is NOT, the function must have a conditional branch between +0x0 and +0x24E that redirects execution.

**Next evidence target:** Install INT3 at 0x8013FCE40 entry and use breakpoint ladder to find the exact branch that skips +0x24E.
