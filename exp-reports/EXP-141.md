## Root Cause Classification

**Current blocker:** WaitSema(0x81) deadlock — bootstrap job never submitted

**Same as:** EXP-124, EXP-127, EXP-134, EXP-135, EXP-137

**What changed since EXP-137:**
- PRXs now properly loaded ✅
- `global-metadata.dat` now properly loaded ✅
- IL2CPP type system now initialized ✅
- Native resolver now working ✅
- No SIGSEGV, no .NET runtime errors ✅

**What didn't change:**
- Semaphore 0x81 is still never signaled ❌
- Semaphore 0x84 is still never signaled ❌
- The bootstrap job is still never submitted ❌
- 13 workers still block on EVEN handles ❌

**The deadlock is in the Unity Job System bootstrap path.** The IL2CPP runtime initializes correctly (metadata loaded, types registered), but the Unity Job System never starts. The main thread enters the dispatch loop and waits for work that never arrives.
