## 1. Real Meaning of Global Address 0x801E51240

### CONFIRMED: [0x801E51240] is an Il2CppClass pointer

**Evidence from rtdump-il2cpp-ps4 (il2cpp_class.h):**

```c
struct Il2CppClass {
    void *image;                    // 0x00
    void *gc_desc;                  // 0x08
    const char *name;               // 0x10
    const char *namespaze;          // 0x18
    Il2CppType byval_arg;           // 0x20
    Il2CppType this_arg;            // 0x30
    Il2CppClass *element_class;     // 0x40
    Il2CppClass *castClass;         // 0x48
    Il2CppClass *declaringType;     // 0x50
    Il2CppClass *parent;            // 0x58
    Il2CppClass *generic_class;     // 0x60
    void *typeMetadataHandle;       // 0x68
    void *interopData;              // 0x70
    Il2CppClass *klass;             // 0x78
    void *fields;                   // 0x80
    void *events;                   // 0x88
    void *properties;               // 0x90
    void *methods;                  // 0x98  ← CRASH OFFSET
    Il2CppClass **nestedTypes;      // 0xA0
    ...
};
```

The crash at `0x80135DE83`: `mov ecx, [rax+0x98]` reads the `methods` field. Since `rax` (from `[0x801E51240]`) is NULL, the access faults at `0x98`.

**[0x801E51240] should contain a pointer to a valid Il2CppClass structure.**

## 3. What Initialization Normally Happens After il2cpp_init()

From rtdump-il2cpp-ps4 (il2cpp_api.cpp):

```
1. il2cpp_init() → loads metadata, creates domain, returns 0
2. il2cpp_domain_get() → returns Il2CppDomain*
3. il2cpp_domain_get_assemblies(domain, &count) → enumerate assemblies
4. For each assembly:
   il2cpp_assembly_get_image(assembly) → Il2CppImage*
   il2cpp_image_get_class(image, i) → Il2CppClass*
   Cache class pointers in EBOOT globals like [0x801E51240]
5. Later code uses cached class pointers:
   [0x801E51240] → Il2CppClass* → methods field at +0x98
```

## 4. What SharpEmu Is Missing

| Stage | Status | Description |

| il2cpp_init | ✅ Works | Native function runs, returns 0 |
| il2cpp_domain_get | ❌ NOT VERIFIED | Should return Il2CppDomain* |
| il2cpp_domain_get_assemblies | ❌ NOT VERIFIED | Should enumerate assemblies |
| Class pointer caching | ❌ NOT DONE | [0x801E51240] stays NULL |

SharpEmu's il2cpp_init runs natively and returns 0, but the IL2CPP API functions (il2cpp_domain_get, etc.) may not return valid pointers. The EBOOT code can't cache class pointers, so [0x801E51240] stays NULL.
