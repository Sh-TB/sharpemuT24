## 4. First Failing Branch After Successful Initialization

With argc=2, the consumer 0x8013EB6B0 passes the first early exit (+0x72, je NOT taken because [0x801E518C8] != 0). However, **[0x801E51240] is NEVER initialized** — it stays NULL.

The init write for [0x801E51240] is at offset +0x3969 (0x8013EF019) inside the consumer function. Static analysis found **22 conditional branches** between +0x72 and +0x3969 that skip past the init write.

The earliest skip branches are:
- +0x277: `jne +0xA234`
- +0x2B6: `jne +0xA234`
- +0x38E: `jne +0xA234`
- +0x3CD: `jne +0xA234`

One of these branches is taken, causing the consumer to skip the init write for [0x801E51240] and proceed directly to the dispatch loop.
