# EXP-187 — IL2CPP Runtime Initialization Validation

**Date:** 2026-08-09
**Status:** ROOT CAUSE FOUND — DT_SCE_INIT_ARRAY not parsed by SharpEmu
**Predecessor:** EXP-186 (IL2CPP API chain never called before crash)

---

## Root Cause: D) SharpEmu IL2CPP implementation is incomplete

**SharpEmu does NOT parse Sony-specific `DT_SCE_INIT_ARRAY` (0x61000017) and `DT_SCE_INIT_ARRAYSZ` (0x61000019) dynamic tags.**

### Evidence:

**PRX dynamic tags:**
- `DT_INIT_ARRAY` (0x19) = 0x0 — standard init_array is EMPTY
- `DT_SCE_INIT_ARRAY` (0x61000017) = 0x0A000000000001 — Sony-specific init_array EXISTS
- `DT_SCE_INIT_ARRAYSZ` (0x61000019) = 0x09000000000009 — Sony-specific size EXISTS

**SharpEmu SelfLoader.cs** only parses:
- `DtInitArray` (0x19) — value is 0, no constructors
- `DtPreInitArray` (0x20) — value is 0

**Does NOT parse:**
- `DT_SCE_INIT_ARRAY` (0x61000017) — **IGNORED**
- `DT_SCE_INIT_ARRAYSZ` (0x61000019) — **IGNORED**

### IL2CPP Initialization Flow (from Katy's blog):

```
Module load:
  C++ constructors run (from init_array)
  → RegisterRuntimeInitializeAndCleanup() populates function table
  → s_Il2CppCodegenRegistration is registered

il2cpp_init():
  → ExecuteInitializations() iterates function table
  → calls s_Il2CppCodegenRegistration()
  → calls il2cpp_codegen_register(&g_CodeRegistration, &g_MetadataRegistration, &options)
  → IL2CPP runtime is fully initialized
  → returns 0
```

### What happens in SharpEmu:

```
Module load:
  DT_SCE_INIT_ARRAY is IGNORED
  → C++ constructors NEVER called
  → RegisterRuntimeInitializeAndCleanup table is EMPTY

il2cpp_init():
  → ExecuteInitializations() iterates EMPTY table
  → does nothing
  → returns 0 (appears to succeed)

Result:
  → il2cpp_codegen_register NEVER called
  → g_CodeRegistration = NULL
  → g_MetadataRegistration = NULL
  → IL2CPP runtime has no metadata
  → [0x801E51240] stays NULL
  → crash at [NULL+0x98]
```

### DT_INIT Function Analysis:

The DT_INIT function at 0x804CD5010 iterates two function pointer tables:
1. Table 1 at 0x804CD50D0 — end pointer [0x808923E88] = 0 → **EMPTY**
2. Table 2 at 0x8089247D8 — first entry = NULL → **EMPTY**

Both tables are empty because the constructors that populate them were never called.

### Sony DT_SCE_INIT_ARRAY Format:

```
PRX:  DT_SCE_INIT_ARRAY   = 0x0A000000000001
PRX:  DT_SCE_INIT_ARRAYSZ = 0x09000000000009
EBOOT: DT_SCE_INIT_ARRAY   = 0x26000000000001
EBOOT: DT_SCE_INIT_ARRAYSZ = 0x25000000000009
```

The format is packed (high byte is a type/flag, low bytes are the value). Exact encoding needs investigation.

---

## Recommended Fix

Implement DT_SCE_INIT_ARRAY parsing in SelfLoader.cs:

1. Add constants for Sony-specific tags
2. Parse DT_SCE_INIT_ARRAY and DT_SCE_INIT_ARRAYSZ
3. Decode the packed format
4. Call constructor functions during module load (before DT_INIT)
5. This populates the RegisterRuntimeInitializeAndCleanup table
6. When il2cpp_init is called, ExecuteInitializations() will work correctly
7. il2cpp_codegen_register will be called → IL2CPP runtime fully initialized
