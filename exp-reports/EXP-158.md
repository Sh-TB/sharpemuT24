## Root Cause Status

**C) PlayerLoop registration failure**

The failure is NOT a crash (decoder hypothesis REJECTED). The failure is a DEADLOCK caused by PlayerLoop registration being skipped. The execution reaches IL2CPP initialization successfully, but PlayerLoop registration never happens, causing the dispatch loop to block on WaitSema(0x81).

## Summary

The TRUE first divergence point is:

**PlayerLoop registration is SKIPPED, causing the dispatch loop to block on WaitSema(0x81).**

There is NO crash. The decoder hypothesis about a crash at 0x80135DE83 is not supported by runtime evidence. The failure is a deadlock, not a crash.

The execution path is:
1. Package loaded ✅
2. PRX loaded ✅
3. dt_init runs and returns 0 ✅
4. Eboot starts ✅
5. IL2CPP type init (38000+ mutex) ✅
6. Worker threads created ✅
7. **PlayerLoop registration — SKIPPED** ❌ ← FIRST DIVERGENCE
8. Dispatch loop entered ✅
9. WaitSema(0x81) → DEADLOCK ❌

The root cause is that the type initialization flags (0x808D67BB8, 0x808D67B98) are never set, causing the gate function (0x804FB8E60) to skip ALL IL2CPP-generated methods, including PlayerLoop.Initialize().
